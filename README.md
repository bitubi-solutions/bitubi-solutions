# Bitubi Solutions

### Ideias que constroem o amanhã.

Desenvolvemos tecnologia para empresas que precisam de evoluir com confiança.

A **Bitubi Solutions** é uma empresa de tecnologia focada na concepção, desenvolvimento e evolução de soluções de software para ambientes empresariais. Combinamos engenharia de software, arquitetura de sistemas e a filosofia open source para criar tecnologia fiável, sustentável e preparada para crescer.

Acreditamos que software de qualidade deve resolver problemas reais, simplificar operações e criar valor a longo prazo.

## O que fazemos

- **Enterprise Software** — Sistemas empresariais robustos, seguros e escaláveis, alinhados com as necessidades do negócio.
- **Software Architecture** — Arquiteturas modernas, integração de sistemas e modernização de aplicações.
- **Open Source** — Desenvolvimento e manutenção de projetos open source, partilha de conhecimento e contribuição para o ecossistema tecnológico.
- **Custom Software Development** — Desenvolvimento de software à medida, desde a concepção técnica até à entrega e evolução contínua.
- **Technology Consulting** — Apoio técnico na tomada de decisões, definição de estratégias e adopção de tecnologias.

## A nossa filosofia

### Engenharia antes de complexidade

Defendemos soluções simples de operar, fáceis de manter e tecnicamente sólidas.

### Open source como princípio

Valorizamos transparência, colaboração e reutilização de conhecimento. O open source permite construir sobre trabalho comprovado, contribuir para a comunidade e reduzir dependências desnecessárias.

### Qualidade para o longo prazo

Desenvolvemos software pensando não apenas na primeira entrega, mas também na segurança, manutenção, observabilidade e evolução do sistema.

### Tecnologia orientada ao negócio

Cada decisão técnica deve responder a uma necessidade concreta e produzir valor mensurável.

## Tecnologia

Trabalhamos com tecnologias e ferramentas modernas, escolhidas de acordo com os requisitos de cada projecto.

O nosso universo tecnológico inclui:

- **Backend:** Java, Spring Boot e APIs REST.
- **Arquitectura:** sistemas modulares, arquitectura hexagonal e integração de serviços.
- **Identidade e segurança:** OAuth 2.0, OpenID Connect e gestão de identidades.
- **Infraestrutura:** Docker, CI/CD e plataformas de execução de aplicações.
- **Dados e observabilidade:** bases de dados relacionais, métricas, logs e monitorização.
- **Open source:** ferramentas, bibliotecas e projectos concebidos para reutilização e colaboração.

Esta lista representa áreas de interesse e competências tecnológicas, não uma restrição às tecnologias que podemos adoptar.

## Open Source

Acreditamos que a colaboração aberta fortalece o ecossistema tecnológico.

A Bitubi Solutions pretende desenvolver e apoiar projectos que possam ser utilizados, auditados, melhorados e partilhados pela comunidade, respeitando a licença e os objectivos de cada projecto.

Os nossos princípios:

- Código claro e documentação útil.
- Licenciamento explícito.
- Versionamento e releases consistentes.
- Contribuições sustentáveis.
- Segurança e qualidade como prioridades.

## Para quem trabalhamos

Colaboramos com organizações que procuram:

- Modernizar sistemas existentes.
- Construir produtos digitais e plataformas empresariais.
- Integrar aplicações e serviços.
- Melhorar a qualidade e a fiabilidade do software.
- Adoptar tecnologias open source de forma estratégica.
- Criar uma base tecnológica sustentável para o crescimento.

## O nosso compromisso

**Construir tecnologia sólida. Resolver problemas reais. Criar valor duradouro.**

A Bitubi Solutions existe para transformar necessidades complexas em software bem concebido, útil e preparado para o futuro.
